# Development Standards

## Branching

- main
- develop
- feature/setup
- feature/database
- feature/auth
- feature/catalog
- feature/cart
- feature/orders
- feature/admin
- release/v1
- hotfix/*

## Commit Convention

Use the following prefixes:

- feat:
- fix:
- refactor:
- style:
- docs:
- test:
- chore:

Examples:

- feat(auth): implement email authentication
- fix(cart): resolve quantity calculation bug
- docs(api): add order endpoints
